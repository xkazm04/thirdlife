# N3 hockey: engine needs (night of 22 Nov)

| Need | Proposed API | Who needs it | Local shim until it lands |
|---|---|---|---|
| A held or loose ball whose speed jumps with no release from the game. A face-off puck squeezed between two skaters left at 27 m/s and scored an own goal for an idle hand. | `TLBall.max_gain(per_frame: float)`: no physics contact may add more than this to the planar speed in one frame. Pack-set velocities (`release`, `shoot_at`, `linear_velocity =`) stay exempt. | hockey; any ball game with bodies around a ball (football, the duel's thrown items later). | `scripts/carry.gd` `_pinch` plus `set_speed_ref`: every pack velocity write is declared, and anything else is capped at max(last speed, 10) + 4 m/s a frame. |
| Goals that count only through the mouth. A puck rebounded 47 m and entered a net from behind the goal line. | A `TLTrigger` option `entry_side` (a plane normal): `entered` fires only for a body that crossed that face. | hockey, football, any game with a goal frame. | `rink_api.gd` `goal_by_position` remembers a puck that came in from behind the line. `main.gd` `_on_goal` no longer scores. |
| Figures overlap in contact. The window clips show bodies inside each other in every scrum. | Exists since 1.13: `TLHit.pushbox`. It is not used yet because it moves every hockey hash and the check model's contact distances were tuned without it. | hockey | none: a future round measures pushbox against the check rate and the metrics. |
| Perception lag for bots: what anybody could see N frames ago. Every AI game needs it, and hockey's ring costs about 20 us a frame in GDScript. | `TLContext.history(frames: int)`: a kernel ring of body positions and velocities, read with `seen(id, lag)`. | hockey, the duel's rivals, any editor game with bots | `scripts/ai/sense.gd` (a 24-frame ring, reused in place) |
| A clean frame for a deterministic sub-rate. An every-other-frame bot steer keyed on `frame % 2` hashed differently in a world than alone. So did the same steer keyed on a count of the brain's own think() calls. A per-skater alternation reset at each face-off also changed play (two seed-1 tests failed). The cause is not established; `frame % 15` staggering passes. | Document which frame `_pack_tick(frame)` receives in a world, and whether a pack can be ticked a different number of times before its first live frame. Add `ctx.own_tick` (the game's own count, equal alone and in a world). | every pack that does anything "every N frames" | none: the steer runs every frame again (the cut is dropped; frame-budget A/B below). |
