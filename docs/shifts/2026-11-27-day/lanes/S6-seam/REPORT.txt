QUESTIONS FOR THE DIRECTOR (gaps the contract leaves; each is an interpretation, named here, not a silent change)
Q1  A taken zone fires no enter, leave or use until the run restarts or the visit ends. The contract has no
    "not taken" condition, so without this a coin rule (enter -> take, add 1) would count again on every re-entry.
Q2  `if` holds at most 8 conditions (IF_MAX). The contract caps `do` (1-8) but names no cap for `if`.
Q3  Triggers made by effects (start, finish, a counter reaching `at`) are read as triggers on the NEXT frame:
    "the triggers are read ... then every fired rule runs" read literally. So "count at 3 -> say" says one frame
    after the third coin, and "on finish" one frame after the finish. Same-frame would need a second pass.
Q4  The start zone (the run's respawn until a checkpoint) is the zone of the starting rule's trigger; when the
    trigger names no zone (count, every, start), the respawn is the floor of the feet cell at the start.
Q5  `count` fires once per run, and once per visit while no run is going (counters are 0 at a visit's start).
Q6  "printable": no C0, DEL or C1 control characters; other Unicode is allowed (names, run names, say text).
Q7  Zone protection (protect.gd refusal_box): game lots, add_box boxes, authored structures and tree trunks by one
    box query; NOT the visitor (he stands in the start zone he draws) and NOT the cell / area rules of other layers
    (pieces, land columns), since zones may overlap blocks. A big zone that touches a tree trunk is refused "tree".
Q8  "In the block grid's bounds": y -16..111 and |x|, |z| <= 100,000 cells (the grid has no x/z limit; paths use
    100 km).
Q9  The brief's `expand_input(op)` is `renumber(ops: Array)` on the rules layer: renumbering needs the whole answer
    (a rule's reference to a zone made in the same answer). home_build.expand_input calls it, so the command tool
    needs no change. Rule: a `zone`/`rule` op's id is the answer's own and gets the next free id in answer order; a
    reference to an id no `zone` op of the answer defines names a Home zone and stays; unzone/unrule are never
    renumbered; an id the answer names twice is refused there.
Q10 run_finished without records (none given): best_frames = frames, new_best false. Starting a run while one goes
    restarts it with no run_stopped call; build mode on / a game on stage / quit drops it with run_stopped(why).
Q11 E is also the visit's "enter a game" key; near a game's gate one press does both (lane P to say what wins).
Q12 Lane C needs a selftest block: the seam holds 773 (seam), 774 (P), 775 (T) only.
Q14 A stamp (tl.stamp/1) carries blocks and pieces only: zones and rules in a stamped box are not taken along
    (the contract names no stamp key for them). A parkour course cannot travel as a stamp yet.
Q13 The rules stop (and reset) while a game is on stage, not pause: the run going is dropped.
