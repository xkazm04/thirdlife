The facade is an interface the play lane implements: name every method with its exact signature in LANES.md, e.g. `set_open(zone_id: int, box: Array, open: bool)`, `launch(up_cm: int, fwd_cm: int)`, `teleport(at: Vector3)`, `say(text: String, frames: int)`, `run_clock(name: String, frames: int)` (or `run_started/run_finished`), `look_taken(zone_id: int, taken: bool)`. A test facade records calls.
4. **`home_records.gd`**: `tl.records/1` read/write (temp, read back, rename, as the build file does), plays/finishes/best_frames, returning "new best".
5. **Stubs and wiring points** for the lanes: `tools/rules_tool.gd` stub in the T cycle (after plants, before command) with the frozen tool/layer/op lists updated through `seam_lists.gd` (754/757 stay green); the place in the visit where `rules_run.step` is called each physics frame while visiting with build mode off (wired, calling a no-op facade the play lane replaces), and how build mode on/off resets a visit's runtime state.
