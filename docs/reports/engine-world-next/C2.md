## PROPOSAL (01:50; the contract for this lane until the Director amends contracts/CARDS.md)

**Card field `hands`** (optional; unknown keys are errors; absent = no hand check):
```
"hands": {
  "seeds": 20,
  "checks": [
    {"hand": "idle",    "wins_max": 0,  "measured": "seed_wall idle 0 of 20 (C2, 18 Nov)"},
    {"hand": "perfect", "wins_min": 16, "measured": "seed_wall perfect 20 of 20, Wilson 95 % 84..100"}
  ]
}
```
- `seeds`: integer 1..40; every check runs on seeds 1..seeds.
- `checks`: non-empty list; `hand` is one of `idle`, `newcomer`, `regular`, `sharp`, `perfect` (TLHand's profiles plus
  `idle`, a player who presses nothing), each hand at most once; at least one of `wins_min`, `wins_max` (integers
  0..seeds, min <= max); `measured`: the row of the example (seed or house pack) that justifies the bound.
- **How a bound is set from a measurement** (so a card never promises more than its example shows): `wins_max: 0` only
  where the example's row is 0 of `seeds` for an idle player (the rule "doing nothing never wins"); `wins_min` =
  floor(lower end of the Wilson 95 % interval x seeds) of the example's row, and only when that is at least 1.
  A hand whose row gives no bound is not checked ("not set: measured k of n" in this file).
- **The pack's side**: for every check, the pack registers `tests/bot_hand_<hand>.gd` (in `registers.tests`), a bot
  that plays the game's own policy through `TLHand.create(ctx, "<hand>")` (idle: presses nothing), finishes when the
  game is over (or at its own frame cap), returns `ok` = it finished and `won` (bool) in `_bot_result()`. `tl cards brief`
  prints the checks into the card block, so the Planner and every builder see them.
- **The Foreman**: at the end of the final verification (after lint, smoke, invariants and every manifest bot, V4),
  when the job's card has `hands`: each check's test runs with verb `bot`, `--seed=1..seeds` (logged `verify` events,
  stem `final-hand-<hand>-seed<k>`). A run that does not finish, a missing test, a result without `won`, or a count
  outside the bounds fails the final verification: **nothing is promoted**; the job ends `failed` with the rows in its
  reason (after a change: `failed`, and pack/ goes back to the last promotion, as any unmade change). Not built tonight:
  sending the failure back to a package for a round (the Planner names who owns the bot; a later lane).
- **`tl cards hands <pack dir> --card <id> [--seeds N] [--tests <dir>] [--par N]`** (the existing `tl cards` command
  extended): runs a card's checks on any pack directory, the same rows the Foreman judges. `--tests <dir>` lays probe
  bots (bot_hand_<hand>.gd) over a temporary copy of the pack, so a pack built before this field can be measured.
