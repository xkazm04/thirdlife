### C3c (knock_down's endless round): proposal, partly built
- **Measured.** seed_wall ends by itself: an idle player's round ends by time at frame 3600 on 20 of 20 seeds. The crate game never ends without a throw.
- **Proposal: no new card field.** Instead, a rule for the hand tests: an idle test has no frame cap of its own. It is done only when the game says over. A round that never ends is then an idle run that never finishes, and "a run that does not finish is never a pass" fails it.
- **Built:**
  - seed_wall's hand tests lost their 7200-frame cap; `tl cards hands` still passes.
  - The card text says "never stop on your own: the game must end its round by itself".
  - Proof on the crate game, using its probe with the cap removed: `FAIL hand:idle [0/3] 0 of 3 runs finished` (3 seeds).
- **Proposed CARDS.md wording**, in "Hand checks": "An `idle` test presses nothing and has no frame cap of its own: a game whose round does not end by itself fails its idle check."

### Proposed JOB.md wording (beyond the 2026-11-18 lines)
"A failed hand check first sends every package that registers a failing `tests/bot_hand_<hand>.gd` back for ONE round. The `reopened` reason and the `queued` detail start `hand check failed`, with the rows. Then the final verification and the hand checks run again. Only a second failure since the last promotion or change request (or a failing test no package registers) ends the job unpromoted."
