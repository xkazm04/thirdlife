---
description: Scaffold a new pack and take it to green
argument-hint: <name>
---
Run `node devx/bin/tl.mjs new pack $ARGUMENTS`, then `node devx/bin/tl.mjs watch --pack engine/packs/$ARGUMENTS --once`.
Read `engine/seeds/README.md` and `engine/kits/KIT.md` before adding any geometry; use kit parts and the `TL*` API only.
